🎮 Dungeon Quest RPG

A simple 2D RPG game developed in Java as my first game development project.

Dungeon Quest is a small adventure game where the player explores a game environment, fights enemies, gains experience, upgrades their weapon, completes a quest, and finally faces the boss.

This project was created as part of my CSE coursework and gave me my first practical experience with Java-based game development.

📌 About the Game

The main goal of the game is simple: defeat the enemies, complete the quest, and defeat the final boss.

The game includes a small RPG-style environment with grass, trees, bushes, rocks, flowers, water, paths, and obstacles.

The player can move around the environment, fight enemies, gain XP, upgrade the weapon, and continue progressing toward the final boss battle.

After completing the required objectives and defeating the boss, the game shows a Game Complete screen.

Key	Action

S	Move Down
D	Move Right
SPACE	Attack
U	Upgrade Weapon
🕹️ How to Play
Start the game.
Use W, A, S, D to move around the map.
Explore the environment and find the enemies.
Press SPACE to attack.
Defeat the required enemies and gain XP.
Use U to upgrade your weapon.
Complete the quest objectives.
Find and fight the boss.
Defeat the boss.
Reach the Game Complete screen.

🎯 Project Goal

The main goal of this project was to learn how a complete game can be built step by step using Java.

Instead of focusing only on writing individual programs, this project helped me understand how different classes and systems can work together to create one complete application.

📚 What I Learned

This was my first game development project, so I learned a lot while building it.

Some of the main things I learned were:

Java class and object management
Object-oriented programming
Java Swing and AWT
Keyboard event handling
Basic game logic
Collision detection
Player and enemy systems
Quest and progress systems
Sound integration
Debugging and testing
Organizing a larger Java project

One of the biggest lessons was that making a game is not only about adding new features. Testing, finding bugs, and fixing small problems are also a major part of development.

🧩 Challenges

While developing the game, I faced several challenges.

Sometimes the game did not run because of coding errors or problems between different classes. Some features also behaved differently than expected after adding new systems.

Another challenge was keeping the different game systems connected properly. For example, enemy defeat, XP, quest progress, boss defeat, and game completion all needed to work together.

Fixing these problems required repeated testing and debugging.

Although some parts were frustrating, solving those problems helped me understand the code much better.


🎓 Project Experience

Dungeon Quest is more than just a coursework project for me. It was my first experience of taking an idea and turning it into a working game.

The project helped me understand that development takes time, testing, patience, and continuous improvement. It also gave me more confidence in working with Java and building larger projects.
